# Nilo

Nilo is an Expo and Express workspace for pages, blocks, typed
databases, comments, sharing, notifications, and real-time collaboration.

<Badge variant="success">App</Badge> <Badge>Workspace</Badge>

## Architecture

- `apps/app` — Expo app for web, iOS, and Android.
- `apps/api` — Express API with PostgreSQL/Drizzle and Socket.IO.
- `@oxy.so/services` and `@oxy.so/core` — Oxy session identity.

Nilo is PostgreSQL-only. It contains no provider adapters, provider-key
store, model router, or inference endpoint. One-shot product operations reach
Kaana through Oxy. Conversations, memory, tools and agents belong to Alia and
then reach Oxy and Kaana. Nilo never calls Kaana directly, and provider
credentials live only in Kaana's encrypted PostgreSQL store.

## Start locally

```sh
bun install
cp apps/api/.env.example apps/api/.env
cp apps/app/.env.example apps/app/.env
bun run dev:api
bun run dev:app
```

The API needs `DATABASE_URL`; the app needs `EXPO_PUBLIC_API_URL`.
